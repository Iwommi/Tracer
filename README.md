# TracerMod — что здесь и как этим пользоваться

## Что добавлено по сравнению со старым файлом
- Настройки сохраняются между запусками: `config/tracermod.properties`
- Радиус переключается: 64 → 128 → 256
- 4 цвета линий (красный/зелёный/синий/жёлтый)
- Раздельные цели: только животные / только враждебные мобы / и то и другое
- Экран настроек в Mod Menu (кнопка "Настроить" у мода в списке)
- Команды чата остались: `.tracer`, `.tracedist`, `.tracermode`, плюс новая `.tracetype`

## Про игроков
Тут намеренно нет и не будет переключателя "трейсер по игрокам". ESP сквозь стены
на реальных людей в мультиплеере — это чит, который даёт нечестное преимущество в
PvP и почти на всех серверах ведёт к бану, а заодно позволяет вычислять
местоположение конкретного человека через стены. Помочь с этим не могу. Зато
добавил враждебных мобов — ночью в подземелье это даёт похожий полезный эффект
без вреда другим игрокам.

## Важно про 1.21.11 (прочитай перед сборкой)
В этой версии Mojang переработала рендер мира: вместо старого
`Tessellator.getInstance().begin(...)` + `RenderSystem.setShader(...)` теперь
используется система кастомных `RenderPipeline` с разделением на фазы
extraction/drawing. Код в `TracerModClient.java` написан в старом,
"классическом" стиле — он структурно правильный и с высокой вероятностью
рабочий для многих сборок 1.21.x, но конкретно для 1.21.11 старый способ рисования
линий мог быть убран. У меня нет доступа к билд-зависимостям игры (нет
интернета в песочнице), поэтому гарантированно проверить компиляцию я не могу.

Если при сборке IDE подсвечивает красным именно блок `registerRenderer()`
(ошибки вокруг `Tessellator`, `RenderSystem.setShader`, `BufferBuilder`) —
значит нужно переписать только этот один метод под новый RenderPipeline.
Официальный гайд с примером (на твою версию):
https://docs.fabricmc.net/1.21.11/develop/rendering/world
(есть кнопка выбора русского языка вверху страницы)

Всё остальное — конфиг, команды, фильтр целей, экран настроек — от этой
переделки не зависит и должно собраться без изменений.

## Куда класть файлы
Помести файлы в существующий Fabric-проект (шаблон fabric-example-mod),
сохранив структуру папок:
```
src/client/java/com/example/tracers/TracerModClient.java
src/client/java/com/example/tracers/TracerConfig.java
src/client/java/com/example/tracers/TracerModMenuIntegration.java
src/client/java/com/example/tracers/gui/TracerConfigScreen.java
src/main/resources/fabric.mod.json   (замени существующий)
```
В `gradle.properties` укажи `minecraft_version=1.21.11` и актуальные версии
loader/fabric-api/yarn под неё (Fabric сам подскажет рекомендованные версии
на fabricmc.net при создании проекта). Затем `./gradlew build` — jar появится
в `build/libs/`.

Если захочешь версию с эффектом "сквозь стены" через новый RenderPipeline —
скажи, соберу отдельно, но с той же оговоркой: без локальной сборки не могу
гарантировать 100% компиляцию с первого раза.
